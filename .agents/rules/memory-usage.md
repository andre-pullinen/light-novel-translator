# Использование базы знаний проекта (memory/)

Все агенты конвейера, работающие с текстом перевода, обязаны сверяться с базой знаний проекта перед началом работы.

## Файлы базы знаний и их назначение

| Файл | Кто читает | Зачем |
|:---|:---|:---|
| `characters.json` | translator, accuracy-reviewer, editor, naturalness-reviewer, review-judge | Пол персонажей (род глаголов/прилагательных в RU), возраст, роли |
| `relationships.json` | translator, accuracy-reviewer, editor, review-judge | Социальная дистанция («ты»/«вы»), форма обращений |
| `speech_patterns.json` | translator, naturalness-reviewer, editor, review-judge | Речевой регистр и манера речи каждого персонажа |
| `glossary.json` | translator, accuracy-reviewer, editor, review-judge | Канонические переводы терминов, магии, рангов, предметов |
| `locations.json` | translator, accuracy-reviewer, editor | Канонические названия локаций и топонимов |
| `lore.json` | translator, accuracy-reviewer, editor, review-judge | Ключевые факты лора, предыстория, правила мира и сюжетные договоренности |
| `style.md` | translator, naturalness-reviewer, editor | Общая тональность, темпоритм, допустимый уровень адаптации |
| `translation_memory.json` | translator, accuracy-reviewer | Устоявшиеся системные фразы, заклинания, коронные реплики |
| `candidates.json` | memory-extractor | Буфер однократных (provisional) сущностей — **не передавать переводчику** |

## Двухуровневая система статусов

- **`confirmed`** — сущность встретилась 2+ раз или является центральной для сюжета. Входит в **обязательный контекст** translator и рецензентов.
- **`provisional`** — сущность встретилась 1 раз. Хранится в `candidates.json`. **Не включается** в обязательный контекст переводчика, чтобы не раздувать промпт.

## Приоритет источников истины

1. **Японский оригинал (JP)** — абсолютный эталон смысла.
2. **`memory/<project>/`** — зафиксированные имена, термины, факты.
3. **Английский промежуточный текст (EN)** — справочный материал.
4. **Русский перевод (RU)** — объект аудита, не источник истины.

## Запреты

- **Не добавлять** сущности со статусом `provisional` в мастер-файлы (`characters.json`, `glossary.json`, `locations.json`) до подтверждения повторного появления.
- **Не передавать** `candidates.json` в обязательный контекст переводчика.
- **Не удалять** записи из `candidates.json` без решения редактора проекта.
- **Использовать только** систему Поливанова для транскрипции японских имён и терминов.
