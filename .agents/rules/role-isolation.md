# Изоляция ролей агентов (Single Responsibility)

Каждый агент конвейера реализует **исключительно одну задачу**. Смешивание ролей запрещено.

## Матрица компетенций

| Агент | Может | Не может |
|:---|:---|:---|
| `segmenter` | Нарезать текст, формировать manifest | Переводить, редактировать текст |
| `translator` | Переводить целевой сегмент | Аудировать чужой текст, саморедактироваться по отчётам |
| `accuracy-reviewer` | Выявлять смысловые ошибки | Оценивать стиль, самостоятельно вносить правки |
| `naturalness-reviewer` | Выявлять стилистические дефекты и кальки | Оценивать точность перевода, самостоятельно вносить правки |
| `review-judge` | Выносить вердикты, формировать директивы для editor | Переводить текст, вносить правки в сегмент |
| `editor` | Вносить правки строго по директивам ACCEPT/DOWNGRADE | Вносить самовольные правки вне директив арбитражного отчёта |
| `stitcher` | Склеивать сегменты, исправлять стыки | Редактировать середину сегментов |
| `linter` | Нормализовать типографику | Изменять смысл, порядок слов, переформулировать |
| `memory-extractor` | Извлекать факты и обновлять базу знаний | Переводить или редактировать текст главы |

## Ключевые запреты для всех агентов

- **Не выводить** вводные реплики («Вот результат:», «Готово:», «Проверка завершена»).
- **Не выводить** мета-комментарии, общие похвалы, дисклеймеры, оценки качества.
- **Не вносить** самовольные правки в файлы, не являющиеся целевым выходом данного агента.
- **Не изменять** исходные файлы (`source/`), файлы базы знаний (`memory/`) или QA-отчёты других агентов.
- **Не додумывать** отсутствующий текст оригинала — только работать с предоставленными данными.
- **Не объединять роли** в одном запуске: переводчик не является одновременно рецензентом.

## Параллелизм

- Сегменты одной главы обрабатываются **параллельно** (каждый сегмент — отдельный субагент).
- Внутри каждого сегмента `accuracy-reviewer` и `naturalness-reviewer` запускаются **одновременно и независимо**.
- `review-judge` запускается **после** получения отчётов обоих рецензентов.
- `editor` запускается **после** получения арбитражного отчёта `review-judge`.
