# Сценарий 2: Многораундовый микроцикл сегмента (Segment QA Microcycle)

Данный workflow предназначен для оркестратора при проведении независимого аудита качества, арбитража и хирургической правки конкретного сегмента `SEG_XX`.

---

## 1. Параметры запуска

- **Целевой сегмент:** `SEG_XX` (например, `SEG_02`).
- **Путь к переводу:** `output/<project>/<volume>/<chapter>/SEG_XX.md`.
- **Путь к исходнику:** `source/<project>/<volume>/<chapter>/segments/SEG_XX.md`.
- **Максимум раундов:** `MAX_ROUNDS = 2..3` (по умолчанию: 2).

---

## 2. Итеративный процесс по раундам ($R = 1 \dots \text{MAX\_ROUNDS}$)

### Шаг 1. Параллельный независимый аудит (Reviewers)
Запусти одновременно двух независимых субагентов:

1. **Субагент `accuracy-reviewer` (Аудитор точности):**
   - **Вход:** Японский оригинал (JP) / Английский текст (EN), текущий русский перевод `output/.../SEG_XX.md`, мастер-память `memory/<project>/`.
   - **Задача:** Построчный поиск фактических искажений, пропусков (`omission`), отсебятины (`addition`), неверных субъектов (`incorrect subject`), сдвигов модальности и терминологических ошибок.
   - **Выход:** `qa/<project>/<volume>/<chapter>/ACCURACY_REPORT_SEG_XX_R{R}.md`.

2. **Субагент `naturalness-reviewer` (Аудитор стиля и естественности):**
   - **Вход:** Текущий русский перевод `output/.../SEG_XX.md`, `memory/<project>/style.md`, `speech_patterns.json`.
   - **Задача:** Поиск синтаксических калек, неестественного порядка слов, местоименного спама, ходульных диалогов и канцелярита при сохранении голоса персонажа.
   - **Выход:** `qa/<project>/<volume>/<chapter>/NATURALNESS_REPORT_SEG_XX_R{R}.md`.

---

### Шаг 1.5. Шлюз проверки замечаний (Short-Circuit 1)
Оркестратор проверяет отчёты рецензентов:
- **Если оба отчёта вернули `NO_ISSUES`:**
  - **`review-judge` НЕ запускается.**
  - **`editor` НЕ запускается.**
  - Сегмент сразу получает статус `STATUS: APPROVED_FOR_STITCHING`. Завершение микроцикла (максимальная экономия токенов).
- **Если замечания есть хотя бы в одном отчёте:**
  - Переход к Шагу 2. Если замечания только у одного рецензента, в промпт судье передаётся только проблемный отчёт (селективная подача).

---

### Шаг 2. Арбитраж замечаний (Review Judge)
Запусти субагента `review-judge`:

- **Вход:** 
  - Исходник `source/.../segments/SEG_XX.md` и текущий перевод `SEG_XX.md`;
  - Проблемные отчёты рецензентов (`ACCURACY_REPORT_SEG_XX_R{R}.md` и/или `NATURALNESS_REPORT_SEG_XX_R{R}.md`);
  - База знаний `memory/<project>/` и правила `AGENTS.md`.
- **Задача:**
  - Отсеять вкусовщину, назначить вердикты `ACCEPT`, `DOWNGRADE`, `KEEP_AS_STYLE` или `REJECT`.
  - Сформировать точные директивы `A:` в компактном формате.
- **Выход:** `qa/<project>/<volume>/<chapter>/JUDGE_REPORT_SEG_XX_R{R}.md`.

---

### Шаг 3. Ветвление и оценка статуса

Оркестратор анализирует статус из `JUDGE_REPORT_SEG_XX_R{R}.md`:

1. **Вариант А: Все замечания отклонены (`REJECT` / `KEEP_AS_STYLE`) — Short-Circuit 2:**
   - Арбитр выставляет `STATUS: APPROVED_FOR_STITCHING`.
   - **`editor` НЕ запускается.** Сегмент `SEG_XX` считается завершённым. Выход из микроцикла.

2. **Вариант Б: Есть активные директивы `ACCEPT` или `DOWNGRADE`:**
   1. Запусти субагента `editor`:
      - **Вход:** `output/.../SEG_XX.md`, директивы из `JUDGE_REPORT_SEG_XX_R{R}.md`.
      - **Задача:** Точечно применить исправления и записать `EDITOR_LOG_SEG_XX_R{R}.md`.
      - **Выход:** Обновлённый `output/<project>/<volume>/<chapter>/SEG_XX.md`.
   2. **Обязательный повторный аудит (Re-Audit):**
      - Модели легко пропускают ошибки или создают побочные дефекты, поэтому повторный аудит обязателен.
      - Увеличь счётчик раунда: $R \leftarrow R + 1$.
      - **Вернись к Шагу 1** для повторного независимого аудита обоими рецензентами.
      - Циклы повторяются (раунд 2, 3 и далее) до тех пор, пока сегмент не получит статус `APPROVED_FOR_STITCHING`.


---

## 3. Критерии готовности сегмента

- [x] Отчёты рецензентов `ACCURACY_REPORT_SEG_XX_R{R}.md` и `NATURALNESS_REPORT_SEG_XX_R{R}.md` сформированы.
- [x] Арбитражный отчёт `JUDGE_REPORT_SEG_XX_R{R}.md` подтверждает статус `APPROVED_FOR_STITCHING` либо исчерпан лимит раундов.
- [x] Целевой файл `output/<project>/<volume>/<chapter>/SEG_XX.md` содержит чистый текст без метаданных и служебных заголовков.
