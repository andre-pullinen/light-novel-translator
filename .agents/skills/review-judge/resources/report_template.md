# Шаблон компактного арбитражного отчёта (Review Judge)

## При наличии замечаний для рассмотрения:

```markdown
ADJ-01 [ACC-01] ACCEPT H
T: [фрагмент перевода RU]
R: [обоснование решения: подтверждено оригиналом / контекстом / правилами проекта]
A: [точная директива для Editor: что заменить на что]

ADJ-02 [NAT-01] DOWNGRADE L
T: ...
R: ...
A: ...

ADJ-03 [NAT-02] REJECT
R: [обоснование отклонения: допустимый стиль, вкусовщина рецензента]
A: пропустить

STATUS: NEEDS_EDIT
SUMMARY: 1 ACCEPT (H), 1 DOWNGRADE (L), 1 REJECT
```

## Если все замечания отклонены (REJECT / KEEP_AS_STYLE):

```markdown
STATUS: APPROVED_FOR_STITCHING
SUMMARY: 0 actionable issues (all rejected/kept as style)
```

## Вердикты (Decisions):
- `ACCEPT` — ошибка объективна. Обязательно к исправлению Редактором.
- `DOWNGRADE` — замечание принято, но критичность снижена. Обязательно к исправлению Редактором.
- `KEEP_AS_STYLE` — допустимый авторский/стилистический вариант. Правка НЕ требуется.
- `REJECT` — замечание необоснованно/вкусовщина. Исключается из пайплайна. Правка НЕ требуется.
