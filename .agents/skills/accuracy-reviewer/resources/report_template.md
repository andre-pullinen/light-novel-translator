# Шаблон компактного отчёта Accuracy Reviewer

## При наличии замечаний:

```markdown
ACC-01 H
S: [исходный фрагмент на JP/EN]
T: [фрагмент перевода RU]
I: [тип ошибки (mistranslation, omission, addition, incorrect subject, modality/tense, terminology) и краткая суть]
A: [минимальная точечная правка]

ACC-02 M
S: ...
T: ...
I: ...
A: ...

SUMMARY: 1 H, 1 M
```

## Если объективных смысловых ошибок нет:

```markdown
NO_ISSUES
```

## Уровни критичности (Severity):
- **H (High / Critical / Major)** — искажение сюжета, смена субъекта действия, смысловой пропуск, искажение знака утверждения, грубое отклонение от глоссария.
- **M (Medium / Minor)** — смена модальности или времени, пропуск второстепенного эпитета/детали.
- **L (Low)** — мелкая неточность, пограничный оттенок смысла.
