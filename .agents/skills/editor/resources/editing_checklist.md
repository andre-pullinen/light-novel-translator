# Чек-лист Редактора (Editor Checklist)
 
При внесении точечных правок по директивам арбитража:
 
1. **Фильтрация:** Вносить правки только по директивам `ACCEPT` и `DOWNGRADE`. Игнорировать `REJECT` и `KEEP_AS_STYLE`.
2. **Хирургическая точность:** Менять только ошибочные слова/фразы, не переписывать окружающие предложения.
3. **Грамматическое согласование:** При замене субъекта или термина согласовать зависимые окончания глаголов, прилагательных и местоимений.
4. **Типографика диалогов:**
   - Длинное тире с неразрывным пробелом: `—\u00A0`.
   - Каждая реплика диалога оформляется отдельным параграфом (`<p>...<p>`) с пустой строкой между ними (`\n\n`), без замыкающих пробелов (`  `).
   - Между повествованием и диалоговым блоком (до и после) обязательно ставится тег `<br>` (`\n\n<br>\n\n`).


5. **Разделители сцен:** Строго `<p align="center">◇◆◇</p>`.
6. **Вывод:** В целевой файл `output/.../SEG_XX.md` сохранять исключительно чистый текст перевода без служебных комментариев.
